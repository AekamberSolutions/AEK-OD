Upload the CONTENTS of this folder to your GitHub repository root.

Required root structure:
index.html
services.html
about.html
contact.html
styles.css
script.js
images/
.nojekyll

Do not upload this folder itself as a subfolder.
Do not upload only the ZIP file.

If the page looks like basic HTML, open:
https://yourusername.github.io/your-repo-name/styles.css

If styles.css gives 404, the CSS file is not in the repo root.
